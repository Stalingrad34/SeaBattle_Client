# План реализации SeaBattle

Клиент — Unity 6. Стек: StateMachine, Zenject, UniRx, UniTask, PrimeTween.
Сервер — Colyseus + TypeScript в папке Server.

| Этап | Что сделать | Время |
| --- | --- | --- |
| 1. Подготовка проекта | Подключить зависимости, подготовить сцену и запуск сервера, проверить соединение Unity с Colyseus. | 2–3 ч |
| 2. Архитектура и протокол | Определить сообщения, сервисы и состояния; разделить контексты двух клиентов; добавить настройки в ScriptableObject. | 3–4 ч |
| 3. Серверная логика | Реализовать расстановку кораблей, выстрелы, очередность, таймер и победу. Скрыть данные соперника. | 3–5 ч |
| 4. Клиент и UI | Собрать две панели игроков, поля, статусы и таймер. Показывать ожидание ответа, блокировать повторные клики. | 4–6 ч |
| 5. Надёжность сети | Обеспечить однократный учёт выстрелов, защиту от старых сообщений, обнаружение разрыва и восстановление после пересоздания клиента. | 6–9 ч |
| 6. Панель отладки | Добавить задержки, потери и дубликаты сообщений, управление соединением, пересоздание клиента, перезапуск сцены и лог. | 3–4 ч |
| 7. Тестирование | Написать серверные и EditMode-тесты правил и пяти рискованных сетевых сценариев. Проверить полную партию и исправить ошибки. | 5–8 ч |
| 8. Подготовка сдачи | Завершить README и AI_NOTES, проверить чистый запуск, записать видео до трёх минут. | 2–3 ч |
